Core Operating Primitives

Built with zero unverified claims and complete reproducibility.

🛡️
Bounded Autonomy
Explicit policy and human-in-the-loop approval thresholds for high-impact analytical actions.
📁
Durable Persistence
JSON File Stores for events, memory graph nodes/edges, workflow DAGs, and audit logs.
🔌
Multi-Source Connectors
SQLite, PostgreSQL, and CSV/JSON sources under unified provider-neutral contracts.
📊
Row-Level Data Diff
Engine to compare datasets, detect schema migrations, and track field modifications.
🔔
Notification Dispatcher
Subscribable alert dispatcher for data quality drops and schema drift warnings.
⚙️
Pipeline Engine
Chained analytical execution workflows connecting profiling, validation, and reporting.
